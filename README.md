# Sistema de Consultorio Médico

Proyecto académico desarrollado en Python para gestionar la información básica de un consultorio médico.

## Funcionalidades

- Registrar pacientes.
- Consultar pacientes almacenados.
- Actualizar la información de los pacientes.
- Eliminar registros.
- Gestionar consultas médicas.
- Almacenar la información en una base de datos SQLite.

## Tecnologías utilizadas

- Python
- SQLite
- Programación orientada a objetos
- Git y GitHub

## Archivos principales

- `sistema_consultorio_medico.py`: contiene el código principal del sistema.
- `consultorio_medico.db`: almacena la información del consultorio.
